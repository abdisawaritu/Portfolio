# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website repository.

This project showcases my background, technical skills, completed projects, and contact information. It serves as a central place where visitors, recruiters, and potential employers can learn more about me and explore the work I have completed.

---

## 📖 About the Project

This portfolio website was developed to present my professional profile in a modern, responsive, and user-friendly way.

The website includes information about:

- My background
- Technical skills
- Featured projects
- Services
- Contact information

The project is fully responsive and designed to provide an excellent user experience across desktop, tablet, and mobile devices.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- AOS (Animate On Scroll)
- Swiper.js
- GLightbox

---

## ✨ Features

- Responsive modern design
- Professional landing page
- About Me section
- Skills section
- Resume section
- Portfolio projects
- Project detail pages
- Contact form
- Smooth scrolling
- Scroll animations
- Mobile-friendly layout
